# ShopMy Developers Documentation

> Documentation for ShopMy Developers

## API Reference
- [Getting Started](https://docs.shopmy.us/reference/getting-started-with-your-api.md): This page will help you get started with the ShopMy API for Brand Partners.
- [Fetch Order Report](https://docs.shopmy.us/reference/fetch-order-report.md): This API request allows brand partners to fetch a report on orders to your brand. This route supports all affiliate program sources and provides detailed info for all ShopMy order records. Orders are returned by transaction date descending (most recent first). A daily rate limit is enforced of 200 requests per day (including paginated requests). At the maximum limit of 500 orders returned per API call, this yields 100,000 orders available for a report per day. Orders are returned sorted by transaction date descending.
- [Getting Started: OAuth Setup](https://docs.shopmy.us/reference/getting-started-with-your-api-1.md): This page will help you get started with the ShopMy API for developers. This API section details authentication steps required to take action on behalf of authenticated ShopMy users via OAuth.
- [Fetch Collections](https://docs.shopmy.us/reference/fetch-collections.md): This API route allows a developer application to fetch a user's ShopMy collections. This route requires the user to permission your app for the read_collections OR write_collections scope.
- [Fetch Links](https://docs.shopmy.us/reference/fetch-links.md): This API route allows a developer application to fetch a user's ShopMy links. This route requires the user to permission your app for the read_links OR write_links scope.
- [Create Collection](https://docs.shopmy.us/reference/create-collection-1.md): This API route allows a developer application to create a ShopMy collection for a user. This route requires the user to permission your app for the write_collections scope. Partner-created collections are always public.
- [Edit Collection](https://docs.shopmy.us/reference/edit-collection-1.md): This API route allows a developer application to edit one of the authenticated user's ShopMy collections. This route requires the user to permission your app for the write_collections scope. Collection privacy cannot be updated through this endpoint.
- [Fetch Profile](https://docs.shopmy.us/reference/fetch-profile-1.md): This API route allows a developer application to fetch the authenticated user's public ShopMy profile information. This route requires the user to permission your app for the read_profile scope.
- [Search Catalog](https://docs.shopmy.us/reference/search-catalog-1.md): This API route allows a developer application to search the ShopMy catalog or resolve a product URL when building a link creation experience. This route requires the user to permission your app for the write_links scope.
- [Affiliate Network Setup Options](https://docs.shopmy.us/reference/getting-started-1.md): This documentation provides setup instructions to integrate with the ShopMy Affiliate Network! By default, the ShopMy network operates with a 30-day cookie window. Additionally, a 30-day return window applies from the transaction date before order amounts are locked and commission is sent out in the next commission invoice.

- [Fetch Order Report Sandbox](https://docs.shopmy.us/reference/fetch-order-report-sandbox.md): This sandbox API request allows brand partners to test API access and responses for fetching a report on orders to your brand. This route is for use in a development environment and returns synthetic data and simulated responses to test API access. A daily sandbox rate limit is enforced of 1000 requests per day (including paginated requests).
